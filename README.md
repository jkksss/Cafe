# Saan Tayo Kape?

A local cafe finder for **Panabo City**, built to help users discover coffee shops, bakeries, restaurants, and late-night hangout spots in the area.

The site presents cafes in a visual card layout with photos, descriptions, price ranges, tags, and an interactive map. Users can filter cafes by tags and sort the results alphabetically.

## Features

- Cafe directory focused on Panabo City
- Interactive map powered by Leaflet
- Cafe markers with map popups
- Dynamic tag-based filtering
- Name sorting (A-Z / Z-A)
- Cafe photo cards
- Estimated price ranges
- Short descriptions for every cafe
- Tags for cafe characteristics
- Responsive layout for smaller screens
- Coffee-inspired visual design
